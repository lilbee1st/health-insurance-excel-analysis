# Health Insurance Expenses and Premium Analysis

## Project Overview
This project uses Microsoft Excel to explore how medical expenses and insurance premiums vary across policyholder groups.

It forms part of my practical learning in healthcare data analytics.

## Project Questions
- How do average medical expenses vary by BMI category?
- How do average medical expenses differ across regions?
- How do average premiums vary by age group?
- How do average premiums differ by gender?

## Dataset
Source: Kaggle — Health Insurance Dataset
Dataset link:
https://www.kaggle.com/datasets/imtkaggleteam/health-insurance-dataset

Records analyzed: 1337

## Tools and Skills
- Microsoft Excel
- PivotTables and PivotCharts
- Interactive slicers
- Summary calculations and KPI cards
- Dashboard design

## Data Preparation
I checked the dataset for missing values, duplicate records, and inconsistent labels. I standardized text labels, verified numeric formats, and formatted the medical expense and premium fields consistently.
I also created BMI categories and age groups to support comparisons across policyholder groups.

## Methods
This project used descriptive analysis.

PivotTables were used to compare:
- Average medical expenses across BMI categories and regions.
- Average premiums across age groups and gender.

Summary measures included the number of policyholders, average medical expense, average premium, and highest single medical expense.

PivotCharts and interactive slicers were used to present and explore the results.

## Dashboard Metrics
- Total policyholders
- Average medical expense
- Average premium
- Highest single medical expense

## Key Findings
1. Policyholders in the obese BMI category had the highest average medical expense at $15,572.04.
2. The Southeast Region had the highest average medical expense at $14,735.41.
3. The 56+ Age group had the highest average premium at $553.40.
4. Male policyholders had a higher average premium than female
   policyholders.
5. Male policyholders had a higher average premium at 272.48, compared with 253.46 for female policyholders.

## Limitations
- The analysis describes patterns within this dataset and does not establish cause-and-effect relationships.
- Group comparisons use averages, which may be influenced by unusually high individual values.
- The findings should not be assumed to represent Nigerian policyholders without evidence that the dataset represents that population.
